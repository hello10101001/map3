드론 연결

상태
꺼짐
수신 기체
0기

드론의 라즈베리파이(drone_agent.py)가 LTE로 Firebase Realtime Database에 위치를 올리고 명령을 받습니다. 설정 → Firebase에서 운영자 계정으로 로그인해야 하며, firebaseConfig에 databaseURL이 있어야 합니다. 드론 번호(droneId) 1, 2, 3…이 드론 관리의 드론 1, 2, 3…과 연결됩니다.

텔레메트리 무선기: 지상용 무선기를 태블릿 USB(OTG 젠더)에 꽂고 ‘연결’을 누르세요. 처음에는 USB 사용 허용 창이 뜹니다. 드론 위치·경로 업로드·이륙·복귀를 무선기로 주고받고(보통 1~2km), 라즈베리파이의 탐지 알림도 무선기로 받습니다.
사진은 무선기로 보내기엔 너무 커서, 태블릿이 파이의 Wi-Fi에 닿을 때(보통 착륙 뒤) 위 ‘파이 Wi-Fi 주소’로 받아 옵니다. 비워 두면 사진은 받지 않습니다.

인터넷 없이 Wi-Fi로: 태블릿을 드론 라즈베리파이의 핫스팟 Wi-Fi에 연결하고 주소에 ws://10.42.0.1:8766(파이 핫스팟 기본 주소)을 넣으세요. 파이에서 브리지를 --local로 켜 두면 위치·명령에 더해 탐지 알림과 칸 사진도 Wi-Fi로 바로 받습니다.
드론과 앱 사이에서 gcs_bridge.py가 MAVLink 위치를 받아 이 주소로 보내 줍니다. 기체 번호(MAV_SYS_ID) 1, 2, 3…이 드론 관리의 드론 1, 2, 3…과 차례로 연결됩니다. 앱을 https로 열었다면 다른 기기의 브리지는 wss:// 주소여야 합니다(같은 패드에서 돌리는 127.0.0.1은 ws:// 그대로 됩니다).

열화상 탐지

탐지 시 진동

드론 라즈베리파이는 주변보다 3°C 이상 따뜻한 점을 탐지로 보내고, 앱에는 열화상 센서가 실제로 잰 온도를 그대로 보여 줍니다 (높이 날수록 사람은 화소보다 작아 체온보다 낮게 잴 수 있음). 이런 탐지에는 기준 온도를 쓰지 않고, 고온 열원 기준 이상만 ‘고온 열원(화재 의심)’으로 나눕니다. 기준 온도는 시뮬레이션·Firebase처럼 주변 온도 차이가 없는 탐지에 씁니다 (그보다 낮으면 표시 안 함). 경로를 업로드하면 기준 온도가 Firebase 임무 문서(thermalMinC)에도 기록되어 드론이 같은 기준을 쓸 수 있습니다.
